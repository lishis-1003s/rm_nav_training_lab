    如何比较参数效果？
    全局：膨胀半径 0.55 → 1.0，观察蓝色范围和全局路径。局部：固定全局参数，局部半径 0.55 → 0.9，观察深蓝范围和实际绕行。动态障碍：导航中移动橙色障碍，观察全局重规划与局部避障。速度：长直道联动速度 0.3 → 1.5，比较实测曲线和耗时。跟随：路径跟随权重 8 → 64，比较实际轨迹与局部轨迹；需勾选重载，重载会取消导航。每轮只改一项。详细步骤见 README。
